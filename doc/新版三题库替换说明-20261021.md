## 身份保护与内容规范化

新版工作簿对大量题目重新编号，不能用相同 Excel ID 覆盖旧数据库 ID。准备脚本以来源、题型、所属目录和原句做确定性、唯一匹配；旧字词题使用已有答案中的词语标签还原被旧占位符替换的词语。只有新旧均唯一的同题保留数据库 ID，答案可更新。未匹配、重复或歧义行采用固定批次 `qb20261021-<原Excel题号>`，每行独立保留，不模糊猜配、不去重。

根据发布前生产内容快照：2952 题保留旧 ID（文学1454、字词662、翻译836），4382 题新建，1809 道未保留旧题下架。完成后为7334道发布题，9143条题目记录；旧修订和学员外键保留。每行原Excel题号、来源行、后台ID和匹配方式完整写入本机 `report.json`。

中文分类映射至现有8个稳定分类；25个文言篇目按完整名称匹配现有ID。不改目录，不新增模型或迁移。

1875道字词题保留原句及括号内词语，按原答案顺序在末尾添加 `释义1：{{0}}` 等答案位。答案是词语解释，不能用解释直接替换句子中的词语。10道缺少占位符的翻译题追加 `参考译文：{{0}}`。774行Excel `_x000D_` 转义解码为换行；不改写题干含义或答案。

原稿有一处仍需内容方校对：字词“题库”第108行 `cla-word-000107` 为“都城过百（雉），国之（害）也。”，有两处括号，但只有“害：祸患，祸害”一个答案。本次保留完整原句，展示一个释义输入位；不虚构“雉”的答案，也不遗漏整题。原表中重复题全部保留。

## 准备与只读预检

`backend/scripts/prepare_questionbank_refresh.py` 只读取工作簿和只含内容的生产快照：

```powershell
python backend/scripts/prepare_questionbank_refresh.py `
  --literature <文学常识题库.xlsx> --words <文言文重点字词.xlsx> `
  --translations <文言文翻译.xlsx> --snapshot <production-content-before.json> `
  --namespace qb20261021 --output <bundle.json> --report <report.json>
```

产物为规范JSON，不生成或更改原始XLSX。包内记录三个原工作簿的文件名、SHA-256、有效题数和每行来源，并校验题号、目录、连续答案和占位符。任何来源行遗漏、公式、断列、重复题号或不明确目录均报错。

在已加载正确环境变量的后端工作目录运行：

```bash
python manage.py refresh_questionbank --bundle /secure/path/bundle.json
```

默认只读、不创建备份、不发布、不修改数据库。预检基线与当前数据库题目/目录有差异时失败，避免覆盖期间人工修改。

## 原子替换

先保留数据库完整备份，再以已有的有效、拥有编辑/导入/发布权限的后台用户ID运行；不在日志打印账号、口令或环境变量：

```bash
python manage.py refresh_questionbank \
  --bundle /secure/path/bundle.json --apply --actor-id <ID> \
  --expect-sha256 <已核对的题库包SHA256> \
  --backup /secure/path/questionbank-before-unique.json
```

备份路径必须尚不存在。命令在事务中锁定题库，对原题更新草稿、沿用现有发布服务生成不可变修订、下架未保留旧题，并写入审计。PostgreSQL额外锁住内容表，阻止导入期间插入新题导致替换漏项；普通读取继续可用。包完全相同时重跑无新修订、无重复题；任何错误整批回滚。回滚JSON保存切换前/后的内容状态，不含学员信息或密钥；不能代替完整数据库备份。

验收逐题核对规范payload与当前发布修订，核对8分类/25篇、3690/1875/1769题量，并确认学员状态、权益、支付、收藏等表无变化。旧题收藏保留历史记录，下架题按已有不可用状态展示；已有随机轮次仍保留历史修订，不删除轮次。

## 回滚

先只读预检，再确认恢复：

```bash
python manage.py refresh_questionbank --restore /secure/path/questionbank-before-unique.json
python manage.py refresh_questionbank --restore /secure/path/questionbank-before-unique.json \
  --apply --actor-id <ID> --expect-sha256 <回滚文件SHA256>
```

恢复旧草稿和发布指针，新题仅下架，不删除题目、修订或学员外键。导入后若已有其他题库编辑/发布，命令拒绝覆盖回滚，须人工核对或使用完整数据库备份。

回滚后可使用同一个规范题库包和新的备份路径再次发布。仅允许本包中内容完全相同、仍未发布的新题作为上次回滚遗留记录存在；不重复新建它们，任何其他人工改动仍会触发基线冲突。
