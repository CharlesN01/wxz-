
然后只从最终 HEAD 生成包：

```powershell
tar --exclude=.git --exclude='*.env' --exclude='*.sqlite3' --exclude='*.db' --exclude='*.tar.gz' -czf wxz.tar.gz $(git ls-files)
Get-FileHash wxz.tar.gz -Algorithm SHA256 | ForEach-Object { "$($_.Hash.ToLower())  wxz.tar.gz" } | Set-Content wxz.tar.gz.sha256
tar -tzf wxz.tar.gz | Select-String '(^|/)(\.env|\.git|.*\.sqlite3|.*\.db|.*\.tar\.gz)'
```

通过条件：工作区无意外修改、本地 HEAD 与远端一致、包只含跟踪文件、旁置 SHA 校验通过。历史压缩包不删除，但不加入 Git、不上传服务器。

### 阶段 F：异常、支付和真机

| 场景 | 通过标准 |
| --- | --- |
| 401 | 自动刷新一次，第二次失败进入登录态 |
| 403/无权益 | 显示受限，不返回受保护答案 |
| 409 | 显示版本冲突，读取服务端版本后重试 |
| 429/5xx/断网 | 明确失败、可重试、不伪报成功 |
| 兼容模式 GET | 正确签名返回 200 和原样 `echostr`，错误签名拒绝 |
| 支付通知 | 重复通知只发放一次，客户端 success 不直接发权 |
| 真机 | HTTPS、登录、返回、安全区、滚动和断网恢复通过 |
