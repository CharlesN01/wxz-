# 应用文新版双主题适配

## 页面与范围

保留 `/pages/application/index` 和现有九个路由。按用户提供的暖色、蓝色 HTML，把旧四类入口与覆盖详情改为同页阅读：安全导航、学习说明、文种横向切换、写作样例／写作要点、题目要求、前后篇。移除固定“开始学习”按钮，不调整全局底栏。

## 数据与交互

- 正文继续调用 `GET /api/student/v1/writings/` 和单条详情，并跟随 `next` 加载全部已发布记录；不导入 HTML 演示内容。
- 文种使用真实 `genreId/genreName`，旧记录无文种时回退实际分类；“全部”跨文种分页。四种现有内容类型保留为可展开筛选。
- 默认显示首条已发布内容。切换文种或类型归零篇号；前后篇按筛选后的真实条目移动，首尾禁用。异步响应只更新当前选中项。
- 写作样例显示后台正文；仅对明确的“写作样例／写作要点／题目要求”章节分区。专项练习显示题目和参考答案。缺少写作要点时明确提示，不生成或伪造教学内容；可返回写作样例查看全文。
- 默认蓝色，提供蓝色／暖色小按钮；仅将主题存本地。两套主题共用阅读交互，不增加路由。
- 保留加载、空列表、筛选为空、详情失败和独立重试。后台控制发布与权限；前端不以原型填充受限正文。
- 离页立即清除正文并使旧请求失效；回页按当前账号重新读取，避免切换账号或开通权益后沿用旧权限内容。允许访问的原篇目在重读后恢复。
- 学习计时继续使用 `withStudyTime`，仅在选中内容已载入、无加载错误时计时。

## 视觉与适配

375 宽原型按 2 倍转换为 rpx，页面左右留白 24rpx；蓝色主色 #247fee，暖色主色 #bb6a5d。英雄卡收紧至原型新版高度，正文卡圆角 24rpx，正文保留换行与长文本折行。使用现有胶囊避让导航，底部仅预留安全区和 32rpx 阅读边距。

## 验收

检查真实分页、文种／类型筛选、双模式、连续翻篇、快速切换请求竞态、错误重试和空态；执行前端测试、项目及原生检查。原型“全部”仍显示第一文种、固定第 1/1 篇是演示脚本缺陷，本实现以真实列表为准。真机与真实内容视觉以主任务集成后验证为准。
