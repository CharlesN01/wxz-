# 文学常识圆润版与底部导航适配

## 页面调整

依据甲方提供的《2文学常识自测版-圆润增强版.html》和《3文学常识背诵版-圆润增强版.html》，在现有文学常识路由内调整两种模式。

- 自测模式增加浅色标题卡、蓝色竖条与装饰圆环；背诵模式使用“阅”字标题卡和“答案版”标记。
- 分类标签圆角 32rpx，题卡圆角 40rpx，模式切换外框 30rpx、内框 24rpx；答案区、收藏、翻页和提示框同步圆润。
- 自测题卡保留左侧蓝色短线；背诵答案继续在原题空位内联显示。
- 保留现有真实输入、答案展开、进度、收藏、服务端分页与权限判断。标题题量使用当前分类接口返回的数据，加载时显示“加载中”，不使用原型固定题量。
- 保留微信安全导航和原生胶囊避让；HTML 内的浏览器模拟顶栏不照搬到小程序。

## 底部导航

首页、收藏、我的、文学常识、文言文目录、文常测试共用导航几何样式，保留原有点击和当前项逻辑。

- 点击行高度 96rpx（390 宽度下约 50px），比原 128rpx 缩短 25%；底部安全区额外占位，不能从点击行内部扣除。
- 图标行高 36rpx、字号 34rpx，文字行高 28rpx、字号 22rpx，图文间距 4rpx；组合在点击行内水平、垂直居中。
- 正文底部避让统一为 120rpx 加 1px 边框和底部安全区，为导航上方保留 24rpx 间距；不再使用首页固定 76px 的旧覆盖。
- 导航贴合窗口底边，宽屏也不增加底部悬空间隙；正文保留底部避让，末尾内容不被遮挡。
- 统一浅色边框、白色背景、顶部圆角；沿用各页面的选中颜色。

## 验收

在 375、390、430 宽度核对自测和背诵页面、六个导航入口，检查横向溢出、长答案和输入框、模式切换、答题进度和底栏居中。分别验证有、无底部安全区的几何关系。运行现有前端测试、项目检查、原生检查和 Git 空白检查；模拟器及真机验收结果分别记录。
