# 文常记小程序视觉差异审计 v1

更新时间：2026-10-16

本审计基于 16 个 HTML 原型和微信开发者工具 375×667、390×844、430×932 三档路由截图。截图已确认 16 个状态均能进入并完成渲染，但本轮没有完成逐像素人工叠图，因此不能把视觉结果标记为 1:1 全部通过。

## 已确认

- 三档各有 16/16 路由截图，页面错误数为 0。
- 首页、文学常识、文言目录、专项练习、随机、收藏、应用文、我的、资料群均有可进入状态。
- 练习页模式切换和首题收藏已用独立 `ws://127.0.0.1:9455` 完成坐标点击复验。
- 截图报告和交互证据分别保存在 `.devtools/automation/acceptance/375`、`390`、`430` 及 `.devtools/automation/physical-practice-9455-*.jpg`。

## 差异记录

### 高优先级

- 原型在 375 宽下使用约 375px 的内容基准并保留较紧凑的题卡和底部导航；当前小程序页面按 rpx 自适应，部分页面内容区更高、更窄，题卡与底部操作栏的垂直比例不同。
- 收藏页原型的默认有数据状态、今日新增数量和题卡排布依赖示例数据；当前页面按 QA 接口真实返回，题数和统计字段缺失时会显示接口实际值，无法与原型示例数字逐项相等。

### 中优先级

- 应用文、资料群等长内容页面的段落间距、底部留白和系统安全区受微信基础库及设备字体影响，与 HTML 浏览器截图存在高度差。
- 文言目录和随机题页面按后端实际题数、分页和轮次显示，原型中的固定示例题数、进度和倒计时不会被前端伪造。
- 资料群二维码或口令由接口配置决定；QA 配置缺少二维码时展示空态，与原型的完整二维码示例不同。

### 低优先级

- 系统字体、状态栏高度、胶囊区域和安全区在开发者工具与 HTML 浏览器之间存在平台差异。
- 原型中的静态图标、阴影和细线在微信 WXSS 栅格化后可能存在 1px 级别的抗锯齿差异。

## 结论与后续

当前视觉验收结论为“路由和状态入口通过，逐像素对照未完成”。高优先级差异需要在下一轮按原型标注逐页调整，并在每个宽度重新截图；真机验收还需要 HTTPS 测试地址和合法 request 域名。数据差异属于接口真实数据与原型示例数据的边界，不应通过硬编码示例数字消除。
