# 文常记小程序 16 状态还原与联调规格 v1

## 目标

保留 9 个原生微信小程序路由，通过页面参数、学习模式和分类状态承载设计稿 16 个页面状态，并完成 API 优先数据流、错误态和视觉验收。

## 状态映射

## 数据和权限

- 所有接口请求统一通过 `services/api.js` 和 `utils/http.js`。
- 公开内容可匿名读取；个人状态、收藏、恢复学习、权益和订单接口必须登录。
- 写请求必须带幂等键；学习状态和偏好写入必须带 `baseVersion`。
- 401 只自动刷新并重试一次；409 显示服务端版本并重试或刷新；403/权益不足展示受限态。
- 网络失败允许本地演示数据降级，但页面必须显示离线/演示数据提示。

## 页面状态要求

每个路由必须处理加载、空数据、接口错误、未登录/无权益和重试入口。模式切换必须清理不适用的答案显示状态；返回、继续学习和随机轮次必须可恢复。

## 验收

- 16 个状态均能从小程序真实入口进入。
- 375、390、430 宽度下检查导航、安全区、题卡、按钮、长文本和底部操作。
- 通过 `npm test`、`npm run check`、`npm run check:native`、JS 语法检查和 `git diff --check`。
- 微信开发者工具模拟器和真实后端登录需单独记录；未执行不得标记完成。

## 范围外

不新增设计稿之外的排名、积分、社交功能；不把占位二维码、口令或支付结果视为正式配置和真实验收结果。
