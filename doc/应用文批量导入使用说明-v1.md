# 应用文批量导入使用说明 v1

应用文批量导入用于将统一 Excel 文件保存成后台草稿。导入成功后仍需使用原有发布流程，小程序才会展示新内容。已有内容在草稿更新后继续展示原发布版本，直到再次发布。

## 入口与权限

- 在“内容管理 → 应用文内容”列表顶部点击“下载模板”或“批量导入”。
- 也可以从侧栏“内容管理 → 应用文导入”或工作台“导入应用文”进入。
- 账号须具有应用文查看、新增权限；更新已有内容还须具有修改权限。新增分类或文种须具有对应查看、新增权限。
- 发布权限单独管理。只有查看或发布权限的账号以及代理本人账号不能导入。

## 下载并填写模板

只使用后台下载的 `.xlsx` 模板，文件最大 5 MiB。“应用文”表最多 1,000 条内容，“分类”“文种”表各最多 200 条。业务表默认为空，四种类型示例及现有分类、文种编号见“填写说明”。说明页内容不会导入。

| 列名 | 填写要求 |
| --- | --- |
| 内容编号 | 稳定且唯一，1～64 位英文字母、数字、下划线或连字符；单元格设为文本，保存后不能改号 |
| 分类编号 | 必填，填写启用分类编号或本次合法新增的分类编号 |
| 文种编号 | 可空；填写时须是启用文种编号或本次合法新增编号 |
| 内容类型 | 写作模板、范文示例、历年真题、专项练习四选一；也接受模板说明中的英文代码 |
| 标题 | 必填，最多 200 字符 |
| 正文 | 必填，最多 20,000 字符；专项练习填题目，其他类型填完整正文 |
| 参考答案 | 仅专项练习必填，其他类型留空；最多 20,000 字符 |
| 排序 | 真正的非负整数，最大 2,147,483,647；留空为 0，越小越靠前 |

正文和答案使用 Alt+Enter 输入单元格内换行，缩进、空行按纯文本保留。填写 `\n` 或 `↵` 只会保留这些字符，不会变成换行。正文中的 HTML、Markdown 也按普通文本展示。

不得增删或重命名表头，不得增加未知工作表、隐藏行列、合并单元格、公式、图片、宏、外链或密码保护。表头顺序可以调整。编号、分类编号、文种编号使用文本单元格，排序使用整数单元格。

“分类”和“文种”表只用于新增字典，不用于修改已有字典。已有编号须与当前名称、排序一致；同名的新编号、停用项和未被内容引用的新增项会报错。无需新增字典时，这两张表只保留表头。

## 上传、预览与确认

1. 默认选择“仅新增”：新编号新增，已有编号且内容完全相同则显示“未变化”，已有编号内容不同则整批报错。
2. 需要更新时选择“新增及更新草稿”：按完整行替换草稿字段。文种留空会清除原文种，排序留空会置 0。文件外的记录保持原状。
3. 点击“上传并预览”，核对新增、修改、未变化和错误数量，以及新增分类、文种数量。展开每行查看原值、新值和完整正文。
4. 有任何错误时整批不能确认，业务数据尚未写入。下载错误报告，按工作表、Excel 原始行号、列名及中文建议修正后重新上传。
5. 无错误后点击“确认导入草稿”。预览及确认凭证仅当前账号可用，有效期 30 分钟；预览后相关内容、发布状态、分类、文种或编号占用发生变化，需要重新预览。
6. 导入结果显示批次及新增、修改、未变化数量。点击“查看本批草稿”只筛选该批涉及的内容；也可逐篇打开内容预览。该入口随私有预览清理失效，之后仍可在应用文列表按内容编号查找；批次审计会保留。

刷新结果页不会重复写入，重复确认已完成批次也不会再次覆盖草稿。若确认请求超时或提示服务故障，应先重新打开该预览链接或按内容编号核对批次结果，再决定后续操作。

## 发布与小程序检查

在本批内容列表中检查草稿，使用“发布所选应用文”，按现有确认页面完成发布。导入功能不替代发布权限、签名确认和冲突检查。

排序影响分类内展示及首屏免费集合；同一分类的四种内容类型共享首屏免费名额，数量沿用学习配置。模板没有单篇“是否免费”或价格列。

导入后小程序未显示时，依次检查：是否已发布、发布版关联分类及文种是否启用、内容类型是否正确、当前账号权益及免费集合、当前使用的 API 环境。

## 常见错误

| 页面提示 | 处理方式 |
| --- | --- |
| 文件或字段错误 | 下载报告，按原始行号修改后重新上传；本批不写入 |
| 权限不足（403） | 联系管理员核对查看、新增及实际所需的修改、字典权限 |
| 预览不存在（404） | 检查当前登录账号，重新上传生成预览 |
| 内容或依赖已变化（409） | 重新上传预览，核对最新差异 |
| 预览过期（410） | 重新上传；过期凭证不能继续确认 |
| 服务暂时不可用（503） | 稍后打开原预览核对批次状态；确认结果未知时先核对，不直接重复覆盖 |
| CSRF 校验失败（403） | 重新打开后台页面，再从页面上传或确认 |

错误报告同样绑定当前操作人，不通过公共媒体地址提供。系统仅接受原文件生成的签名确认凭证，手工修改隐藏字段不会改变导入计划。
