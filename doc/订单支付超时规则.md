# 订单支付超时规则

- 支付期限固定为订单创建时间加 120 秒；重新请求支付参数、关闭支付窗口或重进页面均不延长。
- `created`、`preparing` 且尚未确认付款的订单到期后直接进入 `expired`，后台显示“超时已取消”。超时取消不调用微信查单，不要求人工确认。
- 取消时释放该订单的购买占位，停止对应待执行、执行中或失败的支付任务，记录审计；用户可以重新下单或兑换激活码。订单历史保留。
- 订单列表、详情、支付准备、新下单和激活码兑换均会检查到期状态；独立后台服务每秒扫描到期订单，用户关闭小程序后仍会取消。
- 已确认付款、已开通、激活码待领取或已领取的订单不参与超时取消。迟到的可信付款通知继续进入原有支付状态机，并保持幂等；本地到期不伪造微信平台的关单或退款结果。
- 小程序使用 `statusLabel` 展示中文状态，使用 `expiresAt` 安排到期刷新。`paymentWindowSeconds` 固定返回 120。

## 部署

执行本次 `payments.0006_order_payment_timeout` 元数据迁移后，安装独立的到期服务：

```bash
sudo install -m 644 backend/deploy/chinese-study-order-expiry.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now chinese-study-order-expiry.service
sudo systemctl is-active chinese-study-order-expiry.service
```

单次扫描命令为 `python manage.py expire_payment_orders --limit 200`；常驻命令使用 `--watch --interval 1`。此服务与支付查单任务分开运行，网络查单失败不会阻塞超时取消。
