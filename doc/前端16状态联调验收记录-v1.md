# 文常记前端 16 状态联调验收记录 v1

## 已完成

- 16 个设计稿状态映射到 9 个原生路由，入口参数覆盖 `mode`、`source`、`type`、`articleId`。
- 首页、文学常识、文言目录、字词、翻译、随机、收藏、应用文、我的、资料群均有原生页面承载。
- 页面 API 统一经过 `services/api.js`；学习状态写入包含 `baseVersion`，写请求由 API facade 生成幂等键。
- 文言流程和随机练习优先使用后端分页、固定轮次和续学记录；网络失败时保留本地演示降级并显示来源提示。
- 收藏登录后读取 `/me/favorites/`，支持分页、受限题占位、收藏/掌握同步和版本冲突重试。
- 自测题卡支持查看答案，背诵模式展示答案；练习和随机页支持 URL `mode=writing|reciting` 直达。
- 首页增加资料群入口；375 宽底部操作栏增加可收缩布局。
